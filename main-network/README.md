# NetConnect Main Network Node

主网络节点 - 负责节点发现、消息路由和网络管理（仅命令行运行）

## 功能特性

- ✅ 多播发现：自动发现局域网内的子节点
- ✅ 消息路由：转发节点间的消息
- ✅ 节点管理：维护连接状态和心跳检测
- ✅ 心跳超时检测：30秒超时自动标记离线
- ✅ 轻量级：仅命令行运行，无需 Web UI

## 快速开始

### 启动路由器

```bash
python main.py
```

### 可选参数

```bash
python main.py --port 8888 --multicast-group 224.0.0.1 --multicast-port 5000
```

## 使用说明

1. **启动路由器**：运行主程序即可
2. **查看日志**：终端会显示连接状态和节点信息
3. **子节点自动连接**：子节点启动后会自动发现并连接到路由器

## 系统要求

- Ubuntu 20.04+（推荐）
- Python 3.8+
- 支持 IPv4 多播

## 端口说明

- TCP 通信：8888（默认）
- 组播发现：224.0.0.1:5000
